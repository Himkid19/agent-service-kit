# Contributing

Thank you for improving Agent Service Kit.

## Development

1. Install Node.js 24+ and MySQL 8+.
2. Run `npm ci`.
3. Copy `.env.example` to `.env` and set a local database password.
4. Run `npm run build` and `npm test`.
5. Keep changes focused and add tests for non-trivial behavior.

## Pull Requests

- Describe the user-visible problem and the chosen solution.
- Include verification output or reproduction steps.
- Update API documentation when routes, payloads, status codes, or event formats change.
- Do not include credentials, internal hostnames, customer data, or private datasets.
